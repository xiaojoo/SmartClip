# 装什么、怎么装

SmartClip 自己不捆绑任何外部工具。格式化、文档识别、图上选字、翻译这几件事，
它都是**先认本机装了什么**，认到了就用，认不到就在界面上明说"本机没装"——
不会自己写一个半吊子的替代品蒙过去。

所以刚装好 SmartClip 的一台电脑上，这些功能默认是关着的。这篇写清楚每一样
怎么装、装完要不要重启、怎么确认装上了。

> 装完**不用重启 SmartClip**。设置 → 格式化 那个圆点、设置 → 识别 那句红字，
> 都是每次打开面板现查的。

---

## 一览表

| 想用的功能 | 要装的东西 | 装法（下面各节有细节） | 不装会怎样 |
|---|---|---|---|
| 格式化 C / C++ / C# / Java | clang-format | pip / VS 自带 / LLVM 官网 | 右键"格式化代码"置灰，设置里那三行写"本机没装" |
| 格式化 JS / JSON / HTML / CSS / Markdown / YAML | prettier | `npm i -g prettier` | 同上 |
| 格式化 Python | black | `pip install black` | 同上 |
| 格式化 Go | gofmt | 装 Go 就自带 | 同上 |
| 格式化 Shell 脚本 | shfmt | `go install mvdan.cc/sh/v3/cmd/shfmt@latest` | 同上 |
| 格式化 Rust | rustfmt | `rustup component add rustfmt` | 同上 |
| 格式化 Ruby | rubocop | `gem install rubocop` | 同上 |
| 格式化 PHP | php-cs-fixer | composer 或下 PHAR | 同上 |
| 文档识别（PDF / 图片 / Office → 笔记） | Python + 一个引擎包 | 见「文档识别」 | 拖文件进去直接报"识别程序没配好" |
| 图上选字 PP-OCRv6 | Python + rapidocr + onnxruntime | 见「图上选字」 | 用默认的 Windows 自带那套就行，不装也能选字 |
| 翻译 / 校验 / 截图识别 | 一个 OpenAI 兼容的模型服务 | 见「模型」 | 点翻译直接报"还没配置接口地址（设置 → 模型）" |

内置、什么都不用装的三样：**JSON**（QJsonDocument 重排）、**HTML/XML**（标签缩进
重排）、**纯文本**（去行尾空白 / 收敛空行 / 补末尾换行）。

---

## 先准备 Python

文档识别和 PP-OCR 那两路跑的是随包附带的 Python 脚本，所以要先有一个 Python 3.10+：

```
winget install Python.Python.3.12
```

或者去 [python.org](https://www.python.org/downloads/windows/) 下载安装包（记得勾上
"Add python.exe to PATH"）。

**建议单独建一个虚拟环境**，别把包装进系统 Python——那几个引擎的依赖很重，装坏了
不影响别的程序：

```
python -m venv H:\smartclip-venv
H:\smartclip-venv\Scripts\activate
pip install <下面各节的包>
```

然后在 **设置 → 识别** 里，把「Python」那一格指到 `H:\smartclip-venv\Scripts\python.exe`。

> 为什么非要手动指一次：SmartClip 找 python 先看 PATH，而 PATH 上那个往往是**系统
> Python**，你把包装在 venv 里它就报 `No module named ...`。指到 venv 里那个 python.exe
> 才对得上。（这一条在面板上也写着。）

国内网络给 pip 加个镜像会快很多：

```
pip install -i https://mirrors.aliyun.com/pypi/simple/ <包名>
```

## 文档识别（PDF / 图片 / Office → Markdown 笔记）

三个引擎选一个，**都要先有上面那个 Python**。入口：设置 → 识别 → 引擎。
选完下面那行「识别程序」会自动换成对应的那条命令。

### rapid-doc（默认，推荐先试这个）

```
pip install rapid-doc
```

RapidAI 那套纯 ONNX 文档流水线：版面 + OCR + 表格结构 + 公式，模型都在包里
（约 800MB，第一次跑会下），**CPU 就够，不需要 paddle 也不需要 torch**。
中文材料走这条最省事。

### PaddleOCR-VL（最准，也最重）

```
# 有 NVIDIA 卡走 GPU 那条
pip install paddlepaddle-gpu==3.2.1 -i https://www.paddlepaddle.org.cn/packages/stable/cu126/
# 只有 CPU 就走这条
pip install paddlepaddle==3.2.1 -i https://www.paddlepaddle.org.cn/packages/stable/cpu/

pip install -U "paddleocr[doc-parser]>=3.6.0"
```

大概 3~5GB，第一次跑还会再下约 1.8GB 模型。走的是 PaddlePaddle 原生后端，
Windows 上没问题（vLLM / SGLang 那些加速后端在 Windows 上要 Docker，这里不用）。

### Granite-Docling-258M（最省资源，但中文别选）

```
pip install docling
pip install "transformers>=4.46" torch --index-url https://download.pytorch.org/whl/cu124
```

258M 参数、权重约 515MB，表格结构和公式在同尺寸里很能打，**但语言以英文为主**
（官方把中文/日文标为实验性、未验证）。中文材料请优先上面两个。

### 装完怎么确认

把一份 PDF 拖进主窗口（或 文件 → 识别文档…）。进度出在右下角那张卡片上，
结果是一份新笔记。失败时卡片上会写原因——最常见的两种是"PATH 里找不到 python"
（→ 去设置 → 识别 把 Python 指全）和 `No module named ...`（→ 包没装在您指的那个
解释器里）。

## 图上选字（贴图上按住拖，把图里的字选出来）

默认用的是 **Windows 自带**那套 OCR，离线、不用装任何东西。想换更准的 PP-OCRv6：

```
pip install rapidocr onnxruntime
```

然后设置 → 模型 → 图上选字 选「PP-OCRv6」。下面那行命令默认已经填好
（指向随包的 `ppocr_runner.py`），一般不用动。

## 代码格式化

SmartClip 找这些工具的顺序是：**PATH → 这份文件所在项目的 `node_modules` / `venv`
→ 用户级 bin（`%APPDATA%\npm`、`~\go\bin`、`~\.cargo\bin`、pip 的 `Scripts`）
→ 已知落点（Visual Studio / Qt Creator / LLVM 自带的 clang-format）→ npx 用剩的缓存**。

所以**不装进 PATH 也算数**：项目里 `npm i -D prettier` 装的那一份，格式化这个项目的
文件时就会用它。设置 → 格式化 那个圆点后面的括号会告诉你用的是哪一档（项目里 / npx）。

实在找不到，也可以在那一行的输入框里**直接填完整路径**（例如
`D:\tools\clang-format.exe`），填了就整条覆盖默认命令。

### clang-format

三种来源，任选其一：

```
pip install clang-format
```

- 装过 **Visual Studio**（含 Build Tools）或 **Qt Creator** 的话，机器上其实已经有一份，
  SmartClip 会自己找到（VS 那份常在 `<VS>\VC\Tools\Llvm\x64\bin`，Qt Creator 那份在
  `Tools\QtCreator\bin\clang\bin`），不用再装。
- 想要最新版：[releases.llvm.org](https://releases.llvm.org/download.html) 下载 LLVM 安装包。

### prettier

```
npm install -g prettier
```

或者不装，用一次拉一次：`npx prettier --version` 跑过之后，SmartClip 就能从 npx
缓存里认出它。

### black

```
pip install black
```

### gofmt

装 Go 就自带（`go.dev/dl`），不需要单独装。

### shfmt

```
go install mvdan.cc/sh/v3/cmd/shfmt@latest
```

（用 scoop：`scoop install shfmt`）

### rustfmt

```
rustup component add rustfmt
```

### rubocop

```
gem install rubocop
```

（Windows 上的 Ruby 用 [RubyInstaller](https://rubyinstaller.org/)；装完注意
`gem` 的可执行文件落在 `<Ruby>\bin`，那一档 SmartClip 也会找。）

### php-cs-fixer

```
composer global require friendsofphp/php-cs-fixer
```

或者直接下 PHAR：`https://cs.symfony.com/php-cs-fixer.phar`，然后在设置里把那一行
填成 `php C:\tools\php-cs-fixer.phar fix`。

### 装完怎么确认

随便打开一份对应语言的文件，右键 → 格式化代码。或者直接看 设置 → 格式化：
那一行前面的圆点变绿就是认到了，还是灰的就说明它没找到（把完整路径填进去最稳）。

## 模型（翻译 / 校验 / 截图识别都用它）

两种模式，二选一。设置 → 模型 顶上那两颗按钮切。

### API 模型（用现成的在线服务）

出厂已经把接口地址和模型名填成 DeepSeek 那一套，**只剩密钥要填**：

1. 去服务商控制台建一个 API Key（DeepSeek：`platform.deepseek.com` → API Keys；
   OpenAI：`platform.openai.com` → API keys；通义 / Kimi 同理）。
2. 贴进「密钥」那一格。密钥只存本机（注册表 `HKCU\Software\SmartClip`），
   界面上默认打码，按「显示」才展开。
3. 按「测试连接」。

想用别的服务就把「接口地址」和「模型名」一起换掉，格式都是 OpenAI 兼容的：

| 服务 | 接口地址 | 模型名举例 |
|---|---|---|
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| Kimi | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` |

「识别模型」那一格要填**能看图**的那个（`qwen-vl-max` / `glm-4v` / `gpt-4o`）；
留空就用上面那个模型名去试。

### 本地模型（本程序帮你启动一个）

不想把文件发给在线服务，就本机跑一个 OpenAI 兼容服务。三种常见配法：

- **Ollama**：装 [ollama.com](https://ollama.com/)，然后 `ollama pull gemma3`。
  不用选"本地模型"这一档——Ollama 自己就是服务，切到 **API 模型**，
  地址填 `http://127.0.0.1:11434/v1`，模型名填 `gemma3`，**密钥留空**。
- **LM Studio**：开 Local Server，它会给你一个 `http://127.0.0.1:<端口>/v1`，
  同上填法，密钥留空。
- **llama.cpp**：这一档才是给"本地模型（本程序启动）"用的——
  「服务程序」填 `llama-server.exe` 的完整路径，「模型文件」填一份 `.gguf`，
  端口默认 8080。SmartClip 要用的时候会把它拉起来（加载要几秒到几十秒），
  不用每次手点启动。

### 装完怎么确认

按「测试连接」，或者选中一段中文按翻译。设置 → 模型 顶上那行状态会一直告诉你
现在用的是哪个模型、还差什么：黄字是"只差密钥"，红字是"必填的还空着"。

---

## 都不装会怎样

程序照常能用：剪贴板历史、便签、截图、贴图、Markdown 预览、终端、文件对比这些
都不依赖上面任何东西。只有那四件事会点不动或报错（格式化 / 文档识别 / 图上选字换
PP-OCR / 翻译校验），而且都会当场说清缺的是哪一样、去哪儿填。
